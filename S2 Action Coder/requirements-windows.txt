# S2 Action Coder -- Windows install requirements
#
# Install with:
#   python -m venv .venv
#   .\.venv\Scripts\Activate.ps1
#   python -m pip install --upgrade pip
#   pip install -r requirements-windows.txt
#
# Differences from requirements.txt:
#   - mlx + mlx-whisper REMOVED (Apple Silicon-only; not available on
#     Windows). All mlx_whisper imports in S2 are wrapped in try/except
#     and the app falls back to faster-whisper transparently when MLX is
#     unavailable -- so the Windows build loses the 3-6x Apple Silicon
#     transcription speedup but no functionality.
#   - whisperx ADDED here even though it's not in requirements.txt --
#     S2's PyInstaller spec collects whisperx data + the
#     patches/alignment.py override expects whisperx installed. The
#     macOS workflow installs whisperx implicitly via the .app build
#     pipeline; on Windows we list it explicitly.
#   - pyinstaller ADDED for the build pipeline (was implicit on macOS
#     via the .app build script).
#
# FFmpeg + FFprobe are NOT pip-installable. The app shells out to
# ffmpeg.exe via ffmpeg-python; you need ffmpeg.exe on PATH OR placed
# at S2 Action Coder/bin/ffmpeg.exe before building the installer (the
# spec auto-detects the latter and bundles it).
#
# whisperx pulls in a lot transitively (transformers, torch, ctranslate2,
# soundfile, librosa, etc.) -- the resolved venv ends up ~6 GB. Most of
# that is torch + cuDNN; CPU-only torch would be smaller but breaks
# faster-whisper's CUDA acceleration.
